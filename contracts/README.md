# contracts/

段（S0〜S8）の間で受け渡すデータの契約スキーマを置きます。正本は Notion の契約スキーマ BP で、ここには配布物を置きます。

## 命名規則（契約スキーマ BP §8.1）

```
contracts/<producer>_to_<consumer>/v<major>/
```

- `<producer>`・`<consumer>`：段 ID を小文字で書きます（例：`s3_to_s4`）。
- `v<major>`：互換性のない変更でだけ上げます。互換性のある追加は同じフォルダ内で行います。

## 現状

スキーマはまだありません。最初の契約は、対応する段の実装 PR で追加します。
